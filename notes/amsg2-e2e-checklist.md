# amsg2 这一波的端到端验收清单

> 什么时候用：`feat/amsg2-multitask-gate` 这波（多任务 + 防穿帮闸 + 不降级 + 大内容旁路）
> 合并发布前，照着真机走一遍。
>
> 自动化已经覆盖的不在这里：`pnpm vitest run`（1295 例）跑纯逻辑，
> `node scripts/amsg2-e2e-harness.mjs`（60 项）跑本地全流程。下面只列**它们测不到、
> 必须真人真机真部署**的部分。

## 前置

1. `pnpm vitest run` 全绿、`node scripts/amsg2-e2e-harness.mjs` 60/60。
2. **先贴 worker，再发前端**。这波 bundle 变了（内嵌 amsg-server 2.6.0-next.7），
   顺序反了不炸，只是新前端等 worker 跟上才生效。
3. 贴完在设置页点一次「连接」（走 `POST /init-tenant`，占位租约那列由它补）。

## P0 · 这波新逻辑，自动化测不到

### 1. XHS 分享超过一条 push 的容量

以前硬砍到 4 张，角色说分享 6 张只出来 4 张。现在改成装不下就旁路存云端、客户端取回。

- **怎么触发**：给角色排一条 auto 任务，聊天里先把话题引到小红书，让它到点时分享
  **5 张以上**笔记（笔记标题和描述越长越容易撑爆，正好是要测的场景）。
- **预期**：卡片数量和角色话里说的一致，一张不少；每张都能点开。
- **对不上时看哪里**：Cloudflare 实时日志里找 `[amsg:agentic] XHS 会话数据旁路存储`，
  它会打出旁路前后的字节数。有这行说明 worker 侧存进去了，问题在客户端取回；
  没有这行说明压根没超预算。

### 2. 删角色会不会留下还在跑的远端任务

- **怎么触发**：给角色排一条循环任务 → 删掉这个角色。
- **预期**：删除过程可能卡一下（在取消远端任务），之后不再收到这个角色的推送。
- **顺带测取消失败**：断网状态下删角色 → 应该弹红字提示「还有 N 个任务留在远端没取消掉」。
  之后联网，等这条孤儿任务到点推过来 → 客户端会自己把它清掉（不产生幽灵消息，
  日志里有「清理远端孤儿任务」）。

### 3. 聊完最后一轮，同步没成功的话会不会补上

云端那份 fire_pack 是角色到点唯一的上下文来源，传不上去它就会带着旧上下文说话。

- **怎么触发**：跟一个挂着 AI 任务的角色聊一轮 → **立刻断网** → 等 15 秒去抖触发上传
  （会失败）→ 30 秒后恢复网络。
- **预期**：控制台能看到 `[AmsgStateSync] flush(...) 失败，30s 后重试（第 1/3 次）`，
  恢复网络后重试成功，不再报错。
- **反例（说明没修好）**：失败之后再没有任何重试日志，那份快照就丢了。

### 4. 旧 worker 会不会被误判成最新

- **怎么触发**：如果手边有台还跑着旧 bundle 的部署，连上它。
- **预期**：设置页亮「重新粘贴部署」。贴上新 bundle 后提示消失。
- **说明**：next.4 之后加的能力上游都没发独立 feature flag，所以探测除了查 features
  还会比 `serverVersion`。

### 5. 处理失败时用户看不看得见

- **怎么触发**：不好造。最容易的是走上面第 2 条的孤儿路径，或者浏览器 DevTools 里
  手动把 IndexedDB 关掉再收一条推送。
- **预期**：弹出「有一条消息暂时没能显示，稍后会自动重试」，消息**不进聊天记录**；
  30 秒后自动重试；连着 3 次不行才退回按原文显示，提示改成「已按原文显示，
  表情、卡片这些可能不完整」。

## P1 · 这波主线功能，7-18 之后没在真机上验过

### 6. 多任务

- 一个角色排 2-3 条任务（不同时间、不同循环方式），面板全量显示、能逐个取消/编辑。
- 对话里让角色自己排一条、再让它取消 → 面板和角色说的对得上。
- 到点后每条都按各自的时间触发，内容不串味。

### 7. 防穿帮闸

- **正在聊天时到点**：跟角色聊着天，等一条 `expire` 任务到点 → **不该**收到推送
  （Cloudflare 日志有 `[amsg:expire-skip]`，reason 是 `active-chat-presence`）。
- **作废之后**：下一轮说话时，角色应该知道「刚才那条被作废了」——可能就地把话题
  带进来、可能续期、也可能只字不提，但不该当没发生过（比如原样重发一次）。
- **force 任务**：设成「强制」的任务，正在聊天时到点也照发（闹钟语义）。

### 8. 服务端工具循环

- 排一条需要用工具的任务（回忆某个月的事 / 搜点什么），确认到点时 worker 自己跑完
  工具再生成，客户端全程不用在线。
- 副作用类的（戳一戳、转账、写日记）在客户端收到时重放。

## P2 · 顺带点一下

- **见面·加载更早**：进见面的阅读模式，往上翻到底 → 能继续加载更早的，翻到真没有了
  就停住。
- **思考链 + 工具**：给一个开了思考链的角色配上工具（比如小红书），说句话触发工具 →
  不该再报 400。
- **小程序点单**：在麦当劳/瑞幸点单模式里，让角色顺手排一条主动消息 → 排程应该生效，
  而不是被当成畸形调用吃掉。
- **自部署**：fork 部署仓库 → Cloudflare 面板连上 → 填 D1 的构建变量 → Sync fork
  能触发重新部署。

## 出问题时先看哪儿

| 现象 | 先看 |
|------|------|
| 到点没发消息 | Cloudflare 实时日志：`[amsg:expire-skip]` 是被闸拦了（正常），`[amsg:fire-state-missing]` 是云端状态不全 |
| 收到了但聊天里没有 | 浏览器控制台：post-processing 失败会打日志并弹提示，消息留在收件箱等重试 |
| 卡片数量对不上 | 日志里找「XHS 会话数据旁路存储」，判断是 worker 没存还是客户端没取回 |
| 任务列表标「远端不存在」 | 多半是 worker 版本旧（没有 charId 投影），看设置页有没有亮「重新粘贴部署」 |
| 想看任务实时状态 | 开发者调试面板打开「amsg2 任务观察窗」，右上角常驻小窗有倒计时和通道 trace |
